# 🎬 Netflix Website Clone

A simple Netflix landing page clone built using **HTML** and **CSS**.

---

## ✨ Features

- Netflix-inspired UI
- Responsive Design
- Modern Layout
- Hero Section
- FAQ Section
- Clean User Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
